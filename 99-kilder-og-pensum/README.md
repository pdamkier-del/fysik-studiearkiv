# Kilder og pensum

Ingen konkrete KU-pensumlister eller originale AM-/EM-noter er modtaget endnu. Registrer senere forfatter, titel, udgave, år, relevante afsnit og dokumentets anvendelse. Bevar originale filer uændret. Afklar rettigheder før offentlig deling af kursusmateriale; links og bibliografiske poster kan anvendes uden at kopiere hele værker.
