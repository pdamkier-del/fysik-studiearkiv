# Analytisk Mekanik · universitetsfag

Kursusidentiteten er dokumenteret af brugerens instruktion. Præcist kursusår, officiel kode og sidebaseret pensum er endnu ikke registreret. De fire eksisterende LaTeX-skabeloner er flyttet uændret til formelsamling, udledningsnoter, opgavenoter og opgavesamling; de indeholder ikke færdige kursusnoter.

Forelæsningsnoter og eksamensmateriale har særskilte dokumentpladser. `originaler/` er til uændrede referenceversioner. Eksisterende AM-/EM-formelsamlinger må først importeres, når originalfilerne kan læses; de rekonstrueres ikke fra hukommelsen. Se [originalregisteret](../../docs/originaler.md) og [pensumregisteret](../../99-kilder-og-pensum/README.md).

Kursusnoterne er pensumtro og vedligeholdes uafhængigt af det generelle biblioteks tilsvarende fag. Integrer matematiske forklaringer, forudsætninger og notation i den lokale fysiske fremstilling. Originaler og figurer må ikke overskrives ved genbrug.
