# Termodynamik og statistisk fysik

Dette fag omfatter termodynamik og den tilhørende statistiske fysik. Den autoritative pensumkilde er `Kursusplan_Termodynamik_2026.pdf`; den er endnu ikke fundet lokalt. [Pensumregisteret](../99-kilder-og-pensum/termodynamik-2026.md) bevarer kildestatus og skal senere indeholde præcise sidehenvisninger. Nedenstående er en faglig organiseringsplan på grundlag af brugerens oplyste emner, ikke en gættet bogkapitelinddeling.

| Faglig blok | Oplyste emner | Planlagt behandling |
| --- | --- | --- |
| Tilstande og modeller | Idealgas | Tilstandsvariable, modelantagelser og idealgasrelationer |
| Energi og processer | Hovedsætninger og processer | Energi, varme, arbejde og eksplicitte fortegnskonventioner |
| Entropi | Entropi og multiplicitet | Makroskopisk og mikroskopisk beskrivelse og deres forudsætninger |
| Kredsprocesser | Carnot | Reversibilitet og virkningsgrad med angivne gyldighedsbetingelser |
| Ligevægt og faser | Potentialer og faseovergange | Valg af potentiale, naturlige variable og fasebeskrivelse |
| Statistisk fysik | Boltzmannfordeling, partitionfunktion og Maxwellfordeling | Sammenhæng mellem tilstandsvægte, normalisering og makroskopiske størrelser |

Ensembler hører organisatorisk til sidste blok; præcis kursusdækning afventer kilden. Der tilføjes ikke pensum om uoplyste kapitler eller særlige ensembletyper.

## Dokumenttyper

- `formelsamling/`: formler, symboldefinitioner og gyldighedsbetingelser.
- `udledningsnoter/`: begrundelser, antagelser og udledninger.
- `opgavenoter/`: generelle løsningsmetoder.
- `opgavesamling/`: konkrete opgaver og løsninger.

De fire eksisterende LaTeX-skabeloner bevares uændret. Ved senere indholdsarbejde integreres stoffet i disse dokumenter med fælles design, forklarende dansk tekst, fagligt begrundede vektorfigurer og klikbar navigation. Statistik som metodefag ligger i `06-statistik/`; fælles sandsynlighedsdefinitioner henvises dertil i stedet for at kopieres.
